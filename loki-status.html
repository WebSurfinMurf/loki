📊 API Endpoints

Query Logs

GET /loki/api/v1/query

Query logs at a single point in time

Example: ?query={job="containerlogs"}&limit=100

Query Range

GET /loki/api/v1/query_range

Query logs over a time range

Example: ?query={container_name="traefik"}&start=1609459200000000000&end=1609545600000000000

Push Logs

POST /loki/api/v1/push

Push logs to Loki (used by Promtail)

Labels

GET /loki/api/v1/labels

Get list of known labels

Label Values

GET /loki/api/v1/label/{label_name}/values

Get values for a specific label
